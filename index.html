Pinterest Reorg Tool

Pinterest Reorg Tool is a personal-use utility that helps a single Pinterest account owner organize their own boards and pins. It connects to the Pinterest API using OAuth to let the account owner:

  • Fetch and cache their own boards and pins
  • Detect duplicate or near-duplicate pins using perceptual image hashing
  • Review and (with write access) move, rename, or clean up their own boards and pins

This tool only acts on the Pinterest account of the person who authorizes it. It does not access, store, or share data belonging to any other Pinterest user.
